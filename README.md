# Core Loop Prototype — Lab 3

**Core mechanic:** a minimal 2D PvP fighting-game loop. Player 1 (WASD,
Attack = Space) moves toward Player 2 (Arrow keys) and attacks; landing a
hit flashes and knocks back Player 2 and ticks down their health bar. At 0
HP both players reset to full health and their starting positions, so the
loop repeats indefinitely.

**Controls**
- Player 1: `W A S D` to move, `Space` to attack
- Player 2: Arrow keys to move
